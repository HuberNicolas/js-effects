# js-effects

> A collection of JavaScript visualization effects and interactive Canvas animations, including particles and Mondrian-style patterns.

## ✨ TL;DR
Open `index.html` directly in a browser — no build step required.

## 🚀 Features
- **Particle effects:** Interactive particle animations on HTML5 Canvas.
- **Mondrian generator:** Algorithmic generation of Mondrian-style compositions.
- **Multiple effects:** Various standalone scripts (`script1.js`–`script6.js`) for different visual experiments.

---

## 🛠️ Installation

### Prerequisites
- Modern web browser (Chrome, Firefox, Safari)

### Steps
1. Clone the repository:
```bash
git clone https://github.com/HuberNicolas/js-effects
cd js-effects
```
2. Open `index.html` in a browser.

---

## 💻 Usage

Open `particles/index.html` or the individual HTML files directly in a browser.
